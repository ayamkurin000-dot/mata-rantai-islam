# Integrasi Kartu Ibnu Athaillah

Perubahan paket ini:
- `index.html` diperbarui: node Ibnu Athaillah pada bagian ulama tasawuf kini memiliki 24 anak kartu.
- 24 file HTML ditambahkan ke `data/bio/ibnu-athaillah/`.
- Kartu induk `data/bio/ibnu-athaillah-as-sakandari-penyusun-al-hikam.html` dipertahankan.
- CSS global dan kartu tokoh lain tidak sengaja diubah pada integrasi ini.

Buka peta Tokoh Dunia → Tazkiyatun Nafs → Ibnu Atha'illah as-Sakandari. Pilih tokoh induk lalu buka anak kartu yang diperlukan. Pencarian global juga seharusnya dapat menemukan nama-nama anak kartu.

Catatan: file HTML ini memakai loader `@bio:` yang sudah tersedia dalam proyek. Verifikasi sumber primer dan atribusi setiap kisah tetap menjadi pemeriksaan editorial terpisah.
